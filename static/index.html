    Evaluate the pipeline

    Each question in data/eval_set.json runs through the full pipeline with the strategy you pick below, then an LLM judge scores it.

    • Faithfulness - are the answer's claims supported by the retrieved chunks?
    • Answer relevancy - does the answer address the question?
    • Context precision - are the useful chunks ranked first?
    • Context recall - did retrieval find everything the reference answer needs?

    Tip: edit data/eval_set.json with questions and reference answers from YOUR documents, run the same eval once per strategy, and compare the scores.
